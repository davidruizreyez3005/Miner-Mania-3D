# Build reports

Generated by `blender/build.py` (not versioned):

- `build_report.json` / `build_report.txt` - build status, asset counts, triangle totals, warnings, errors.
- `validation_report.json` - standalone GLB inspection results (`tools/validate_assets.py`).
- `gltf_validator_report.json` - Khronos glTF-Validator results (`tools/gltf_validate.mjs`).
- `godot_import_report.json` - Godot headless import validation (`godot/pipeline/validate_assets.gd`).
- `previews/` - review thumbnails re-imported from the exported GLBs (QA aid only).
