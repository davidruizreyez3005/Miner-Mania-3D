# Build reports

Generated by the pipeline (not versioned; CI uploads them as artifacts):

- `build_report.json` / `build_report.txt` - `blender/build.py`: build status, per-asset stage timings, triangle totals, animation counts, allowed warnings and errors.
- `standalone_validation.json` - `tools/validate_assets.py`: every manifest file re-inspected from disk (checksums, budgets, skeletons, clips, stale files) plus the negative self-test.
- `khronos_validation.json` - `tools/gltf_validator/validate.mjs`: the official Khronos glTF-Validator in strict mode.
- `godot_validation.json` - `godot/pipeline/validate_assets.gd`: what Godot imported (scenes, triangles, materials, bounds, sockets, skeletons, clip loop modes, track binding, collision shapes, shared humanoid rig).
- `previews/` - review thumbnails re-imported from the exported GLBs (`--previews`, QA aid only).
